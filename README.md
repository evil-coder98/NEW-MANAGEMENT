# NEW MANAGEMENT — browser prototype

## Run
Open `index.html` in a modern browser, or upload the files to a GitHub Pages repository.

## Editable content
- `data.js`: intro paragraph, class colours, class stat ranges, names, employee generation, abnormality generation, audio paths.
- `style.css`: all interface colours, room appearance, layout, typography and responsive styling.
- `audio.js`: playback behaviour and panic music selection.
- `game.js`: game systems and interactions.

## Facility layout
Each floor has:
- One central main room.
- Hall 1 and Hall 2.
- One containment chamber connected to each hall.
- A vertical connector to the adjacent floor.

The facility currently adds one new abnormality per shift, placing two containment chambers on each floor.

## Current prototype scope
This is an initial playable systems prototype. It includes the three phases, crate selection, employee hiring, generated names/stats, containment rooms, exercises, sanity, energy quota, breach state, suppression orders, sacrifice, shift timer, wages, death fees and a basic information panel.

The next development pass should expand employee navigation and combat, armour/weapons, detailed abnormality-specific AI, save/load, more robust economy balancing, panic escalation rules, and polished character/room animations.
