# NEW MANAGEMENT V0.3

Browser game prototype. Open `index.html` or host the folder with GitHub Pages.

## Editable files
- `data.js`: balance, classes, quirks, names, armour shop and content.
- `style.css`: visual palette, layout and UI.
- `audio.js`: music and sound playback.
- `game.js`: simulation and interactions.

## V0.3 systems
- Hire from generated employee applications: Researcher, Suppressor or Janitor.
- Random employee speed and stats; employees no longer require manual naming.
- Offtime inventory tabs: EGO Weapons, EGO Gear, ARMORS and EGO Gifts.
- Purchaseable armour, employee equipment assignment and one-owner equipment rules.
- Sacrifice an abnormality while its sanity is above 50 to recover one EGO weapon and one EGO suit per abnormality.
- Preferred-sin researchers can earn one abnormality-exclusive EGO gift after repeated successful preferred exercises. Gifts are bound to that employee and are lost if they die.
- Employee corpses remain in the facility; janitors automatically clean them. Researchers lose sanity while near remains.
- Shift recovery, suppressor passive recovery, breach penalties and suppression recovery.
- Class 3+ abnormalities can spawn with unique quirks.
- Floors are ordered downward from Floor 1 to reflect the underground bunker.
- Initial energy quota is 5.

This remains an evolving prototype. Quirk effects are modular and the current set is a first batch; further behaviours can be added in `data.js` and `game.js`.
